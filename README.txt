LIGOZZA BILLING APP — PC + ANDROID

This package is a Progressive Web App (PWA). It can be installed on Android and on supported desktop browsers (including Chrome/Edge on Windows).

IMPORTANT INSTALL REQUIREMENT
For the install prompt and offline app mode, publish these files to an HTTPS website.
You can publish this folder using GitHub Pages:
1. Extract the ZIP.
2. Upload all files inside LIGOZZA_Billing_App to your GitHub Pages repository (keep the files together).
3. Enable GitHub Pages in repository Settings > Pages and wait for the HTTPS site URL.
4. Open that URL in Chrome on Android, tap the browser menu, then "Install app" or "Add to Home screen".
5. On Windows, open the same HTTPS URL in Chrome or Edge and choose the Install icon / menu > Install this site as an app.

FEATURES
- 40 starter products; edit names and prices, with support for up to 150.
- Add multiple products and quantities to one invoice.
- Customer name, phone, address, discount, payment method and note.
- Invoice numbering begins at LG-2006001.
- Print A4 invoice or choose Save as PDF.
- Sales history stored locally.
- Export/import JSON backup.
- Logo upload.
- Offline use after the app has loaded once and cached.

DATA NOTE
This version stores data separately on each device/browser. PC and Android do NOT automatically share product lists or sales. Use Export backup on one device and Import backup on the other to transfer data. Automatic cloud sync requires a backend/database and secure hosting.
